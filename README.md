# 🚀 LeetCode Daily Practice

Repository theo dõi quá trình luyện tập thuật toán LeetCode hàng ngày, tối ưu hóa giải thuật và xây dựng bộ kiểm thử Unit Test.

## 🛠️ Công nghệ & Kiến trúc
- **Ngôn ngữ chính:** C# (.NET 8.0 / .NET 9.0)
- **Kiểm thử tự động:** xUnit Test Suite
- **Quy trình phát triển:** Dual-Branch Pull Request Architecture
  - Nhánh `test/*`: Bổ sung kiểm thử đơn vị (Unit tests & Edge cases)
  - Nhánh `feat/*`: Giải thuật tối ưu và tài liệu giải thích
  - Tech Lead Code Review: Phê duyệt (Approve) với nhận xét chuyên môn và Squash & Merge vào nhánh `main`
