# Asymptotic Complexity Reference (.NET 9 / C#)

| Structure / Algorithm | Time Complexity (Avg) | Space Complexity |
| :--- | :--- | :--- |
| `Dictionary<TKey, TValue>` Lookup | `O(1)` | `O(N)` |
| `PriorityQueue<TElement, TPriority>` Enqueue/Dequeue | `O(log N)` | `O(N)` |
| `Array.Sort<T>` (IntroSort) | `O(N log N)` | `O(log N)` |
| Two Pointers / Sliding Window | `O(N)` | `O(1)` |
